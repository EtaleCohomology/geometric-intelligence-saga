# Gallery ── 登場人物たちの画集

GI ケーススタディ・ストーリーの登場人物たちの画集です。次の２つを収めています。

1. **テーマ別の画集（PDF）**：本編には登場しない場面を、テーマごとに集めた画集
2. **登場人物ごとの肖像画（フォルダ）**：各作品の「登場人物」のページに載せた肖像画を、人物ごとに、作品の順に並べたもの

## 1. テーマ別の画集

画集は、ケーススタディの作品ごとではなく、テーマごとにまとめています（1つのテーマの画集に、複数の作品の時期の場面が入ることがあります）。1冊は、Word に画像を並べ、場面を説明するキャプションを付けて、PDF にしたものです。

### 本編との関係

- どの画集の場面も、本編の年表と人物の設定に沿っています。ただし、本編には登場しない場面です
- キャプションには、その場面が物語の中のいつのことかを書いています
- 本編を読んでいなくても楽しめるように作っていますが、本編を読むと、場面の意味が深くなります

### ファイル名の決まり

```text
<公開した順の番号>_<作品のフォルダ名>.jpg
```

例：`Lin/01_construction-industry.jpg`、`Lin/02_semiconductor-equipment-industry.jpg`

- 作品のフォルダ名は、[case-studies](../case-studies) の中のフォルダ名と同じです。どの作品の肖像画かが分かります
- 同じ作品に、同じ人物の肖像画が２枚あるときは、`_1`、`_2` を付けます（例：`03_textile-industry_1.jpg`）

- 登場する人物、会社、組織は、すべて架空です。実在の人物に似せていません
