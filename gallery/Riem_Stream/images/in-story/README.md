# in-story ── 本編に載せた画像

ケーススタディの本編に載せた、リームの画像を置くフォルダです。

いまは、まだ画像を置いていません。

## ファイル名の決まり

```text
<作品のフォルダ名>_<本編でのファイル名>.jpg
```

- 作品のフォルダ名は、[case-studies](../../../../case-studies) の中のフォルダ名と同じです。どの作品の画像かが分かります
- 本編でのファイル名は、その作品の `images/` の中のファイル名と同じです
