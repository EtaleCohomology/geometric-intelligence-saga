# Riem Stream ── リーム・ストリーム

メリディアン・ジオメトリック・インテリジェンス社の創業者兼 CEO、リーム・ストリームの画像を集めたフォルダです。

## このフォルダの中身

| 場所 | 中身 |
|---|---|
| `<番号>_<作品のフォルダ名>.jpg` | 各作品の「登場人物」のページに載せた肖像画（公開した順） |
| `*.pdf` | リームの日々を、テーマごとに集めた画集（キャプションつき） |
| [`images/in-story/`](images/in-story) | 肖像画のほかに、ケーススタディの本編に載せた画像 |
| [`images/gallery-only/`](images/gallery-only) | 本編には載せず、このフォルダにだけ置く画像 |

### ファイル名の決まり

**肖像画**（このフォルダの直下）

```text
<公開した順の番号>_<作品のフォルダ名>.jpg
```

例：`01_construction-industry.jpg`

- 決まりは、ほかの人物のフォルダと同じです（[../README.md](../README.md)）
- 同じ作品に肖像画が２枚あるときは、`_1`、`_2` を付けます

**本編に載せた画像**（`images/in-story/`）

```text
<作品のフォルダ名>_<本編でのファイル名>.jpg
```

例：`ramen-manifold_<本編でのファイル名>.jpg`

**本編に載せない画像**（`images/gallery-only/`）

```text
<場面>.jpg
<物語の中の年月>_<場面>.jpg
```

例：`station-platform-with-coffee.jpg`、`2040-05_<場面>.jpg`

- いまある画像は、物語の中の時期を決めていないため、年月を付けていません
- 時期を決めた画像には、`Kaito_and_Lin/` と同じく、先頭に年月を付けます
- 同じ場所の似た場面が複数あるときは、末尾に `-a`、`-b`、`-c` を付けます（例：`gelato-at-market-hall-a.jpg`）

## 本編との関係

- どの画像も、本編の人物の設定に沿っています
- `gallery-only` の画像は、本編には登場しない場面です
- リームの服は、画像ごとに違うものを着ています

## ご注意

- 登場する人物は、すべて架空です。実在の人物に似せていません
- 実在の店、商品のブランドのロゴや名前は、描いていません
- 画像は、Google Gemini により、Étale Cohomology の指示のもとで生成したものです（[../IMAGE_CREDITS.md](../IMAGE_CREDITS.md)）
