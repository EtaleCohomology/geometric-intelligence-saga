# カイトとリンの年表 ── 週末のラーメン屋めぐりから、シャンティイまで

メリディアン社のカイトとリンが、同僚から恋人になり、結婚し、リンの実家とリンの伯父を訪ねるまでの流れを、物語の中の日付の順に並べました。

## ご注意

- 日付は、すべて物語の中の日付です
- 「公開済み」の作品は、すでに GitHub に公開しています。それ以外の作品は、執筆中または執筆の予定で、題名、日付、場面は、書いていくうちに変わることがあります
- この年表には、まだ公開していない作品の筋が含まれます。本編を先に楽しみたい方は、ご注意ください

## ２人について

- **リン**：メリディアン社のシニア数理アナリスト。フランス国籍。口癖は「その前提、確かめさせて」。パリの北、シャンティイの近くで、馬を育てる家に生まれた。過去の作品で描かれた、ある事件のあと、実家で静養し、それ以来、家族と少し距離を置いている
- **カイト**：メリディアン社のシニアソフトウェアエンジニア。日本人。データの網の目の偏りにはすぐ気づくのに、目の前の人の気持ちには、なかなか気づかない
- ２人とも、仕事の性質上、国の秘密を扱う資格を持っている。そのため、２人の関係が進むたびに、英国とフランスの決まりに従って、届けを出していく
