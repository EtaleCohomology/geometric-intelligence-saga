### ファイル名の決まり

**本編に載せた画像**（`images/in-story/`）

```text
<作品のフォルダ名>_<本編でのファイル名>.jpg
```

例：`eight-eyes-connection_ee_S05_confession.jpg`

**本編に載せない画像**（`images/gallery-only/`）

```text
<物語の中の年月>_<場面>.jpg
```

例：`2040-05_moving-day_kiss.jpg`

## 本編との関係

- どの画像も、本編の年表と人物の設定に沿っています
- `gallery-only` の画像は、本編には登場しない場面です
- リンの髪型は、交際を始める前は後ろで結び、交際を始めてからは肩にかかる長さに下ろしています（荷ほどきや料理のときに結い上げている場面もあります）
