# 個人・一族編 — 百年の測地線

**── 生存者たちのサロン ──**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

数学は、百年の迫害を生き延びてきた知恵に、何を加えられるか

## あらすじ

2048年9月、ロンドン。メリディアン・ジオメトリック・インテリジェンス社の CEO リーム・ストリームのもとに、痕跡を残さない招待状が届く。差出人の名も、返信の宛先もない。案内されたのは、ハムステッド・ヒースの森に隠れた18世紀の邸宅で開かれる、記録の上には存在しないサロンだった。

集まっていたのは、住む国が揺れるたびに少数派として標的にされうる立場を、何世代も生き延びてきた一族の当主たちである。1492年のスペインの追放令から5世紀をかけて移り住んできたセファルディムの一族、ワルシャワ・ゲットー蜂起を生き延びた家系、香港から資産と家族をオーストラリアとカナダに分けた華僑の姉弟、モロッコとイスラエルを経てパリに住む一族、そして1972年にウガンダから追放されたインド系の商人の子孫たち。

彼らの問いは1つだった。「あなたの地図で、私たちの一族が生き延びる見込みを、20％高められますか」。

リームは、地図に「できること」と「できないこと」を、正直に分けて答える。越えたら戻れない線（境界）までの近さと、その近さが縮む速さ。原因と結果の輪と、出来事の順番。公開されている見積もりとの並べ読み。そして、地図が学べるのは、記録を残せた人の歴史だけだという限界。何百年もの生存の知恵は、数学の外にあった。それでも、数学は、その知恵に「あと数日」を加えられるかもしれない。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。本作は、その方法を、企業でも政府でもない、個人と一族の依頼に初めて当てはめる作品である。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。本作は、実在の国、組織、人物を評価するものではない。法律、制度、公開されている見積もりの記述は、2026年11月の時点の事実にもとづく。

## 本作で扱うデータ解析の現場課題

**境界までの近さと、縮む速さ**
- 越えたら戻れない線を、仮説として地図の上に引き、そこまでの近さを測る。近さが縮む速さを、地図の上の流れに沿ったリー微分で表す
- 「空気が変わった」という人の感覚を、同じ一歩で大きく揺れるようになる場所として読む

**原因と結果の輪と、出来事の順番**
- 原因から結果へ矢印を引いた図の閉路を列挙し、一周したときに最初の強まりが何倍になって戻るかを測る
- 同じ２つの出来事でも、起きる順番で結果が変わる。その差をリー括弧で測る
- 人づての話に繰り返し現れる「長く残る輪」を、パーシステント・ホモロジーで見つける

**地図に「できないこと」**
- 地図が学べるのは、記録を残せた人の歴史だけである（生存者バイアス）。選び方が作る見かけの関係（バークソンの偏り）
- 公開されている見積もり（大量殺害の危険の早期警報）と、自分たちの地図を、互いに置き換えずに並べて読む
- 百年を一度に予測しない。10年ごとに地図を作り直す

**道を分け、早めに、少しずつ動く**
- 互いに交わらない道の数と、切り離すためにふさぐ場所の数（メンガーの定理）
- 危うさで測った距離が短い道（測地線）
- 急に大きく動くと輪を強めてしまう。舵の大きさに代償を書き込んだ最適制御で、早めに、小さく、ゆっくり動く

**合図の基準と、守る側の線**
- 見逃しと空振りの釣り合い。合図の基準をどこに置くかは、一族が決める
- 合図の計算が、紙に書いた約束（仕様）どおりかを確かめる。検査と形式証明の違い
- 秘密を見せずに、正しいことだけを示す（ゼロ知識証明）。マネー・ローンダリング対策の法律の内側で、見せ方を選ぶ
- 利益相反の確認。「私たちの盾は、私たちだけのものであってはならない」
