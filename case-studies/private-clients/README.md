# 個人・一族編 ケーススタディ

企業でも政府でもない、個人と一族からの依頼に、GI (Geometric Intelligence) 理論を当てはめるケーススタディ。

これまでのケーススタディは、企業と政府を守る物語だった。個人・一族編では、住む国の変化が一族の暮らしと命に直結する人々の問いに、地図が「できること」と「できないこと」を分けて答える。依頼の中身は公にされないことが多く、記録を残さないこと、法律の内側で見せ方を選ぶこと、利益相反を確かめることも、分析の一部として描く。

## 公開済み

### [diaspora-families-century-resilience/](diaspora-families-century-resilience/) — 百年の測地線
**── 生存者たちのサロン ──**

2048年、ロンドンのハムステッド・ヒースの邸宅で開かれる、記録の上には存在しないサロン。何世代も迫害と追放を生き延びてきた一族の当主たちが、リーム・ストリームに問う。「あなたの地図で、私たちの一族が生き延びる見込みを、20％高められますか」。

#### 本作で扱うデータ解析の現場課題

- 境界までの近さと、その近さが縮む速さ（リー微分）
- 原因と結果の輪（閉路）と、出来事の順番（リー括弧）。人づての話に残る輪（パーシステント・ホモロジー）
- 地図が学べるのは、記録を残せた人の歴史だけ（生存者バイアス、バークソンの偏り）。公開されている見積もりとの並べ読み
- 互いに交わらない道（メンガーの定理）、危うさで測った測地線、早めに少しずつ動く最適制御
- 見逃しと空振りの釣り合い、仕様の検査、ゼロ知識証明、利益相反の確認
