# サイドストーリー（番外編）

Étale Cohomology は、GitHub で、ジオメトリック・インテリジェンス（GI）理論の理論書（複数のファイル）と、GI理論のケーススタディ（業界別、政策領域別）を公開している。あわせて、Qiita に関連記事を公開している。

Qiita の関連記事には、まず、GI理論を紹介する記事がある。さらに、GI理論を構築していく過程を、ケーススタディに登場するキャラクターたちが発案し、議論しながら描いていく、ショートストーリーのシリーズ記事がある。

今回、そのうち、Qiita に番外編として公開した5本の記事（番外編1〜5。公開は2026年3月下旬）と、番外編としては公開しなかったものの、6作目の番外編と位置づけることのできる Qiita の記事1本（番外編6）を、GitHub に公開する。
