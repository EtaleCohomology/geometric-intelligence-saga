# 【GI理論（番外編１）】「7社7通りのAI Agent、重複禁止で設計してください」—— 経営環境多様体デジタルツイン上のAI Agent設計（前編）

リームのベンチャーに、世界的な大企業7社から、AI Agentの精度検証の依頼が舞い込む。条件は2つ ── 7社それぞれに異なるアーキテクチャのAgentを、重複なしで提案すること。そして各社に、身体を持たないAgentと、デジタルツインの中で身体を動かすAgent（Embodied AI）の2体を提案すること。リルル先生と研究室のメンバーは、AI Agentのアーキテクチャの全体像を整理し、「時間スケール」「不確実性の構造」「意思決定の粒度」の3つの軸で、6社にAgentを割り当てていく。
