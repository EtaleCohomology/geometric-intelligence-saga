# 社内・自主研究編 — 中華麺の多様体

**── チャーシューは、本当に薄くなったのか**

ジオメトリック・インテリジェンス ケーススタディ・ノベル（番外編）

## あらすじ

2038年４月、ロンドン。メリディアン・ジオメトリック・インテリジェンス社のソフトウェアエンジニアのカイトは、ソーホーの外れの行きつけの店「らぁ麺 巻雲」で、ふと思う。「チャーシュー、薄くなってないか？」

カイトは、開店のころから、食べるたびに自分の丼の写真を撮ってきた。リンとユキが加わり、勤務の時間の外で、無償の、私的な調べものが始まる。３人は、調べてよいことの線を先に引き、店の帳簿には手を出さず、自分たちが買って食べた杯の記録と、誰でも見られるデータだけを使う。斜めに写った丼の縁の楕円から写真を真上から見た形に戻し（射影変換）、いつから変わったか（ベイズ流のオンライン変化点検出）、何のせいか（差分の差分）を調べる。

途中から、社長のリーム・ストリームと、東京から来た数学顧問の長谷部 健が加わる。長谷部は、ベンフォードの法則に飛びつこうとしたカイトを「そこで止まってください」と止め、ラーメン店の席で、２つの流れのリー括弧を計算し、電磁シールドの会議室で、レンゲと菓子鉢で、非可換性とホロノミーを語る。

結果を受け取った地方自治体の取引基準局の調べで、店主が量を減らした事情が明らかになる。物語の後半、話は、太鼓の形を音で聞き分けられるか、という問いから、GI 理論の地図そのものの品質を、ラプラシアンの固有値と固有関数でどう点検するか、そして、非可換幾何学の中で GI の地図がどこに立っているか、という問いへ広がっていく。

数学の名前に飛びつかず、データが数学の前提を満たしているかを確認すること。知らないことは、知らないと言っておくこと。それが本作の主題である。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。物語の現在は 2038年だが、制度と数字は、2026年11月の時点の調べにもとづいて書いた。物語には、実在する飲食店等を思わせる場所や料理が登場するが、店の名前は記しておらず、これらの飲食店等と物語の内容には一切の関係がない。

## コードの実行

    pip install -r code/requirements.txt
    cd code/figures
    python ramen_py01_area_ratio.py

ほかの図も、同じように実行する。計算に使う数値は、物語の中の架空の数値か、説明のために作った架空のデータである。図の日本語は、Noto Sans CJK JP のフォントで描く。コードは、実行するコンピューターに Noto Sans CJK のフォントがあれば、自動で見つけて使う。各コードは、計算の結果を assert で点検する。
