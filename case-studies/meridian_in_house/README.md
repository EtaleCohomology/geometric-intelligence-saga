# 社内・自主研究編 ケーススタディ

顧客の依頼ではなく、メリディアン・ジオメトリック・インテリジェンス社が、自らの発意で取り組むケーススタディ。

これまでのケーススタディは、企業、政府、個人と一族からの依頼に応える物語だった。社内・自主研究編では、依頼主はいない。社員の小さな疑問や、会社自身の事業の構想から調べものが始まり、ときに、GI (Geometric Intelligence) 理論そのものを点検し、拡張する方向へ進んでいく。調べてよいことの線を先に引くこと、確からしさの言葉で結論を書くこと、外部の専門家に何を尋ね、何を尋ねないかを決めることも、物語の一部として描く。

## 公開済み

### [ramen-manifold/](ramen-manifold/) — 中華麺の多様体
**── チャーシューは、本当に薄くなったのか ──**

2038年4月、ロンドン。メリディアン社のソフトウェアエンジニアのカイトは、ソーホーの外れの行きつけのラーメン店で、ふと思う。「チャーシュー、薄くなってないか？」。勤務の時間の外で始まった無償の私的な調べものは、写真の幾何と時系列の統計を経て、やがて、GI 理論の地図そのものの品質を、ラプラシアンの固有値と固有関数でどう点検するか、という問いに行き着く。

#### 本作で扱うデータ解析の現場課題

- 調べてよいデータの線引きと、選択の偏り（公開の写真と、自分の写真）
- 斜めに写った丼の縁の楕円から、真上から見た形に戻す（射影変換とアフィン近似、面積の比）
- いつから変わったか（ベイズ流のオンライン変化点検出）、何のせいか（差分の差分と平行トレンド）
- 使ってはいけない数学を止める（ベンフォードの法則の前提）。専門家の座標と、フィッシャー計量の階数
- 順番で答えが変わる（リー括弧、レヴィ面積、混合差異）
- GI 理論の拡張の候補：ラプラシアンの響き方による地図の品質の点検（島の数、響き方、叩く場所、次元）。結果は「合格」ではなく「黄信号」で書く
- 非可換幾何学から GI の地図を見直す（スペクトル三つ組、コンヌの距離、２枚の地図、スペクトルの切り捨て）
- ヒューミント、保安の習慣、外部の専門家に尋ねるときの線引き

### [evidence-sheaf/](evidence-sheaf/) — 証跡の層
**── デジタルフォレンジック会社編 ──**

2038年９月、ロンドン。東京の小さなデジタルフォレンジック会社の創業者が、メリディアン社に問いを持ち込む。「政府の公的なチームが記録保全の最初の数時間を担うようになりました。私たちの会社は、何を担い、何を手放すべきでしょうか」。物流倉庫で AI エージェントが区画を自動で切り離し、証拠が消えた夜の記録を、リン、カイト、ユキは層（sheaf）の計算で貼り合わせる。GI 理論の地図が使えた問いと、使えなかった問いを、メリディアン社の人々が自分たちで見つけ、書き残す。

#### 本作で扱うデータ解析の現場課題

- 時計のずれた十数か所の記録を、セルラー層で１本の時間に貼り合わせる（時刻で変わる制限写像、輪の上の食い違い）
- 輪がなければ食い違いは見えない（１次のコホモロジー、メンガーの定理による「輪のある記録」の設計）
- 時計を信じずに言える前後（ランポートの半順序）、対応のない記録の対応づけ（グロモフ・ワッサースタイン距離）
- 証拠の重み（尤度比と確信度、別の説明の一覧）、暗号化の範囲の見積もり（エントロピー）、戻る速さ（クープマン作用素）
- 中身を見せずに改ざんがないことを示す（マークルの木、ゼロ知識証明）
- エタール層とセルラー層の違い。機械学習が使うのはセルラー層
- GI 理論の地図の得意と不得意。聞き取りの倫理と、意思決定者の重圧への寄り添い方
