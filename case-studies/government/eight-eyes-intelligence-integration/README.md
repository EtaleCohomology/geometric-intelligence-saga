# 政府編 — Eight Eyesの多様体

## あらすじ

2030年3月、同じ夜に、東京、ケルン、パリ近郊で、3人の分析官がそれぞれ小さな異変に気づく。日本海の通信の時間帯のずれ、ドイツの造船関連企業への侵入、フランスのソーシャルメディアのアカウント群の規則的な動き。3つの断片は、3つの国の報告書の片隅に書き留められただけだった。4週間後、それが欧州の艦艇のインド太平洋への派遣を標的とする一つの作戦の部分だったことが判明する。

すでに自国の多様体を運用していた日本と英国は、この「4週間の遅れ」を出発点に、米国、カナダ、オーストラリア、ニュージーランド、ドイツ、フランスの6か国に、ジオメトリック・インテリジェンスという分析の基盤を共有することを提案する。各国の窓口での国内の合意の取りまとめ、韓国・インド・台湾それぞれの距離、北京の公式・水面下の反発、欧州の首脳たちの決断。そして、提案が中国やロシアを囲い込むものではないことを水面下で伝え、日中の防衛当局のホットラインや議員外交、経済界の交流といった、関係を支える回路も同時に強めていく。

ロンドンのSCIFに集まった8か国25名の連絡官とメリディアン社は、PRISMやXKeyscoreのような既存の基盤を置き換えるのではなく、その上に解析の層を重ねる「Eight Eyes多様体」を設計する。Neural Sheaf Diffusionによる整合性の検証、モース理論と臨界減速、ベッチ数とヴァインヤード、Lie括弧による政策の順序効果と創発の予兆、ZKMLと形式検証による議会への説明。そして、検閲されたデータで作った多様体がなぜ体系的に過信へ傾くのかを、情報理論で明らかにする。

本書は、『ジオメトリック・インテリジェンス』理論（論文と手引書）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。物語の舞台は2030年前後で、その土台は本書の執筆時点（2026年10月）の現実の国際情勢である。
