# 白夜の臨界

**ジオメトリック・インテリジェンス理論の北極海LNG保険リスクへの適用**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

## あらすじ

2030年夏、北極海。制裁によって西側のP&I保険を失ったロシアのLNGタンカーは、ロシアなど３か国の保険会社による保険プールの代替保険のもとで航行している。その保険は、国際的な補償の枠組みの外にあり、LNGの事故の補償を定める条約も、ロシアの水域には届かない。保険の空白と法的空白が、北極海航路の上で完全に重なっている。

フィンランド金融監督庁のアクチュアリー、ソニア・ハルビネンは、「誰も公式には認めていないその空白の形を、数学は証明できるか」という問いを、ロンドンのメリディアン社に持ち込む。わずか７件の事故の記録から、極値理論で、１シーズンに少なくとも１回、保険プールの引受キャパシティを超える事故が起きる確率 ── 臨界確率 κ_c ── を推定する。

同じ頃、モスクワでは、ロシアのAI「БЕЛЫЙ-7」が起動する。嘘を１つもつかず、正しい数字だけを恣意的に選んで、ロンドンの保険市場と合同戦争委員会（JWC）のリスクの見方を変えようとする。メリディアン社は、循環フィルトレーション、統計学の検定、極値理論の３つの数学で、その情報操作の痕跡を捉えようとする。

本書は、『ジオメトリック・インテリジェンス』理論（論文と手引書）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、作中でリルル教授が考案する「循環フィルトレーション」（実在の数学と整合するよう設計したフィクションの概念）を除き、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。物語の舞台は2030〜2031年で、その土台は本書の執筆時点（2026年10月末）の現実の動向である。
