# 半導体製造装置業界編 — 光稜の巡回差

**── ホロノミー**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

## あらすじ

2031年4月、日本の半導体製造装置メーカー・光稜精機株式会社は、ふたたびロンドンのメリディアン・ジオメトリック・インテリジェンス社に分析を依頼する。光稜精機の計測装置で、お客さまが同じウェハーを測っても、府中で補正した装置と、米国で補正した装置とで、数値が0.1ナノメートル前後食い違う。原因は、計測装置のクセなのか、それとも装置どうしを比べるために拠点の間を運ぶ「基準ウェハー」が変わってしまったのか。同じころ、中国の当局は半導体の計測のデータを重要データとして通知し、米国の規制は米国人の技術者による中国の先端の工場の保守を制限する。中国向けの保守の事業を、別の会社に分けるべきか。

リーム・ストリーム率いるメリディアン社のチームは、光稜精機の技術戦略部の社内チームとともに、基準ウェハーを拠点の間で一周させて測る「一周の差」（離散的なホロノミー）と同期問題で、基準ウェハーが変わった区間を突き止め、補正値を正しく直す。規制が両立するかは、ファルカスの補題とSATソルバーで判定し、分けるか待つかは、実物オプションで判断の境目を示す。

物語の中では、若手のカイトとリンが、ファイバー束の曲率やチャーン類を計測のデータに当てはめようとして、リームに前提の不足を指摘される。数学の名前に飛びつかず、データが数学の前提を満たしているかを確かめること。それが本作の主題である。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。2031年の時点の規制の細部も、架空の設定を含む（本書のまえがきに、2026年11月上旬の時点の規制と出典を記載）。

## 登場する数学と手法

離散的なホロノミー（一周の差）、同期問題、最小二乗法、線形混合モデル、統計的な検定、層、変化点の検出（CUSUM）、カルマンフィルタ、実験計画法、ファルカスの補題、SATソルバー（最小の矛盾の組）、実物オプション

## コードの実行

    pip install -r code/requirements.txt
    python code/ch4_ch5_metrology.py
    python code/ch4_design_ch5_cusum.py
    python code/ch6_ch7.py

計算に使うデータは、物語の答えを仕込んで作った架空のデータである。図を描くコード（code/figures/）は、日本語のフォント（Noto Sans CJK）の場所を、環境に合わせて書き換えてから実行する。
