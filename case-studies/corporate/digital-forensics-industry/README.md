# デジタルフォレンジック業界編 — 証跡の層

**── 何を担い、何を手放すか**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

## あらすじ

2038年９月、ロンドン。東京の小さなデジタルフォレンジック会社、株式会社 黒曜デジタル鑑識の創業者 御影 律子が、メリディアン・ジオメトリック・インテリジェンス社のリーム・ストリームを訪ねる。「政府の公的なデジタル・フォレンジックチームが、記録保全の最初の数時間を担うようになりました。私たちの会社は、何を担い、何を手放すべきでしょうか」。

リームは、黒曜がいま抱えている事件を、正式な同意を得たうえで題材にすることを提案する。埼玉の物流会社の倉庫で、AI エージェントが区画を自動で切り離し、メモリの中の証拠が消えた夜の事件である。十数か所の機械が、それぞれの時計で刻んだ記録を、リン、カイト、ユキは層（sheaf）の計算で貼り合わせる。いちばん大きな食い違いは、2038年問題による時計の故障だった。小さく静かな食い違いの向こうには、１人で２人分の夜勤をしていた担当者がいた。

GI 理論の経営環境多様体の地図は、黒曜の進む道の問いには向いていたが、事件の記録には使えなかった。メリディアン社の人々は、そのことを自分たちで見つけ、正直に伝え、最後に、地図が得意な領域とほかの手法が求められる領域を、誰にも頼まれずに書き残す。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。物語の現在は 2038年だが、制度と数字は、2026年11月の時点の調べにもとづいて書いた。本作は、攻撃を受けた側と、その側に立って記録を調べる側の分析だけを描き、攻撃の手口は書かない。

## 登場する数学と手法

セルラー層と層ラプラシアン、0次と1次のコホモロジー（大域切断と輪の上の食い違い）、定数の層とグラフラプラシアン、時刻で変わる制限写像と茎の設計、頑健な標準化と整合性の半径、持続的層ラプラシアンの考え方、ヴァイスファイラー・レーマン検定とグラフニューラルネットワークの表現力、フィードラー値、グロモフ・ワッサースタイン距離、ランポートの半順序、ローレンツ多様体と因果集合、スミスの規則と交換子、尤度比と確信度（ENFSI の指針、ICD 203）、シャノンのエントロピー、クープマン作用素と動的モード分解、マークルの木、ゼロ知識証明、メンガーの定理、2038年問題とうるう秒、有限体とヴェイユ予想、フロベニウス写像、ガロア群、エタール層とエタール空間、アレクサンドロフの位相、圏論と可換図式、楕円曲線のさざめき（murmurations）

## コードの実行

    pip install -r code/requirements.txt
    cd code/figures
    python s01_cellular_sheaf_clocks.py

ほかのコードも、同じように実行する。計算に使う数値は、物語の中の架空の数値か、説明のために作った架空のデータである。図の日本語は、Noto Sans CJK JP のフォントで描く。
