# 投資ファンド業界編 — 曲率の裁定

**── 平坦な確率空間が崩壊するとき**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

## あらすじ

2032年3月、ニューヨークの架空のヘッジファンド Math Universe Capital Asset Management（MUCAM）で、モデルの推定を、実際の損失が３倍以上も上回る。MUCAM のクオンツたちは、裾の厚い分布、極値理論、コピュラ、ランダム行列理論、ラフ・ボラティリティを使いこなす、統計学と確率論の専門家である。それでも、現実はモデルの外側にあった。CRO のエレナ・チェンは、ロンドンのメリディアン・ジオメトリック・インテリジェンス社に分析を依頼する。

リーム・ストリーム率いるメリディアン社のチームは、「データで示せないことは、報告書に書かない」と約束し、分布どうしの距離を何の距離で測るか（フィッシャー情報計量とワッサースタイン距離）、共分散行列の多様体、通貨の一周のずれ（離散的なホロノミー）、資金洗浄の輪（パーシステント・ホモロジー）、売りと買いで違う執行の費用（フィンスラー計量）などで、MUCAM の市場の地図を描いていく。

市場が荒れる中、MUCAM の社内では、インターンの大学院生・杉田 純を講師役に「多様体の勉強会」が始まる。統計学に明るい MUCAM の人々は、多様体、位相幾何学、微分幾何学を自ら学び、メリディアン社に知的な闘争を仕掛ける。「推定した計量は、真の計量ではない」「あなたたちの地図は、曲率を計算できるほど、なめらかなのか」「点の集まりから、本当の空間の穴を、どうやって見分けるのか」「なぜ VAE なのか」。互いに前提を確かめ合った両社は、最後に、新たな秘密保持契約のもとで、数学の概念とデータへの当てはめ方の妥当性を議論する、常設の知的対話の場を設ける。

数学の名前に飛びつかず、データが数学の前提を満たしているかを確かめること。それが本作の主題である。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。物語の中の国際情勢は、2026年11月の時点で現実に議論されている動きを延長した、架空の設定である。物語には、実在する飲食店等（レストラン、割烹・料亭など）を思わせる場所や料理が登場するが、店の名前は記しておらず、これらの飲食店等と物語の内容には一切の関係がない。

## 登場する数学と手法

情報幾何学（フィッシャー情報計量、フィッシャー・ラオ距離、統計多様体と双対接続、チェンツォフの定理）、最適輸送（ワッサースタイン距離）、共分散行列の多様体、多様体の条件（コンパクト性・なめらかさ・フルランク・単射性）、離散的なホロノミーと離散版のストークスの定理、微分形式と外積代数、パーシステント・ホモロジーとジグザグ・パーシステンス、コホモロジー（閉じた1形式と完全な1形式の商）、層、フィンスラー多様体（ランダース計量）、アレクサンドロフ空間、伊藤の確率積分、極値理論、期待ショートフォール、ランダム行列理論、ラフ・ボラティリティ、ホークス過程、最適な執行（Almgren・Chriss）、モデル・リスク管理（SR 11-7。2026年4月に SR 26-2 に置き換え）、Task Arithmetic・TIES-Merging、スタック型の設計（VAE・拡散写像・Neural ODE・形式検証）、Gluzman 氏の戦略多様体との比較
