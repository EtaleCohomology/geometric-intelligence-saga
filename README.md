# 企業編 — 複式の境界

**── MUCAM の投資先 ４社 ５年の時間差攻撃**

ジオメトリック・インテリジェンス ケーススタディ・ノベル

## あらすじ

2037年5月、米国のヘッジファンド MUCAM（Math Universe Capital Asset Management）のプライベート・エクイティの部門が投資する3社が、同じ週に、そろって大きな傷を負う。日本の産業用ポンプのメーカーは減損と繰延税金資産の取崩しで純資産を削られ、ドイツの冷凍冷蔵物流の会社はのれんの減損のあと株価が下げ止まらず、日本の水産物と冷凍食品の専門商社は、大口の取引先に代金を払われないまま逃げられる。業界も、国も、会計基準もばらばらの3社は、1つの冷たい供給網の上で、モノ、お金、信用、株式でつながっていた。

MUCAM の CRO エレナ・チェンの依頼を受けたロンドンのメリディアン・ジオメトリック・インテリジェンス社は、相手が財務モデルという「地図」の上で、どこを押せばどこが崩れるかを読んでいたことに気づく。チームは、会計の恒等式を、正しい決算書が入る空間の形としてメリディアンの地図に課し、融資の契約書の財務制限条項の線を、契約書の定義どおりに地図の境界として引く。地図ができあがると、3社の傷は、2033年の後半から少しずつ仕込まれていたことが分かる。

次に狙われる4社目を、境界までの近さで予測し、先回りして守る。そして、打撃の順番と時期から、相手が何を最大にしようとしていたかを逆算する。相手のモデルの2つの癖 ── 財務制限条項を、契約書の定義（単体）ではなく公開の連結の数字で判定していたこと、狙う会社を欲張り法で選んでいたこと ── が、遠い国の銀行に残された、ある財務モデルとの照合の手がかりになる。

敵は、自分たちの財務モデルに裏切られた。

本書は、『ジオメトリック・インテリジェンス』理論（第1巻・第2巻）を企業や政府機関で経営施策や政策の立案に役立てるための使用方法を、ケース・スタディ・ストーリー形式で示すことを目的とする。

ケース・スタディ・ストーリー中に登場する数学とデータ処理・データ解析技術・人工知能技術は、すべて実在するものである。なお、ケース・スタディのストーリー展開は架空の物語であり、登場する人物・組織も架空の存在である。会計基準、四半期の開示、金融商品取引法、国際的な協力の枠組みの記述は、2026年11月の時点の制度にもとづく。

## 本作で扱うデータ解析の現場課題

**相手の地図を、こちらの地図に重ねる**
- 財務モデル（3表連動、DCF、LBO、M&A、FP&A）とは何か。会計の決まりで必ず成り立つつながり（骨組み）と、事業の仕組みから生まれるつながり（仮説）を分ける
- 会計の恒等式を満たす点の集まりはアフィン部分空間で、負になれない勘定科目の条件を加えると凸多面体になる。デコーダの出力を、そこへ射影して会計の決まりを必ず守らせる
- 射影の内積は、描き戻しの誤差の大きさから決める。同じ出力が、内積の選び方ひとつで、財務制限条項の線の上にも下にもなる
- 複式簿記はパチョーリ群で、グロタンディーク群の構成の最も簡単な例の1つである。群が保証するのは骨組みで、中身は会計基準が決める

**存在しないデータと、壁の内側の数字**
- 日本の第1・第3四半期の決算短信では、キャッシュフロー計算書と株主資本等変動計算書がそろわない。欠けた表を推測で埋めない
- 投資先の月次の管理会計の数字を、業務の契約と秘密保持契約のもとで受け取り、数字に触れる人と株を売買する人の間に情報の壁を立てる
- 当局に渡す結論は、すべて公開の情報で計算し直す

**つながりの変化と、見えにくい方向**
- 恒等式で決まる勘定科目を外した PCMCI による、遅れのある因果の推定と、構造の変わり目の検定（探した回数の補正）
- 可制御性と可観測性のグラミアン（線形の近似と経験グラミアン）で、動かしやすいのに公開の決算書には映らない方向を探す
- バークソンの逆説、並べ替えの検定、リー括弧、レオンチェフの逆行列とスペクトル半径
- 最大固有値が最も大きい部分グラフを探す問題の NP 困難性と、欲張り法の癖という指紋

**崖は、契約書の中に書いてある**
- 財務制限条項の線を、単体か連結か、判定の日、比べる時点まで、契約書の定義どおりに勘定科目の空間で引き、地図に引き戻す
- 毎期動く線を、去年の数字を状態に加えて、動かない折れ線にする。判定の日にだけ見る
- 形式検証で、条項の計算が、契約書の文言を書き直した仕様と一致することを証明する。書き直しが法律の上の意味と一致するかは、人が読む

**事実だけを選んで並べる相手と、先手**
- ベイズ説得、母集団を先に決める選択の偏りの検定、ホークス過程による連鎖の強さの推定（決算の日の山を先に入れる）
- ロバスト制御とシュタッケルベルク・ゲーム。仮定した相手の手の範囲を、紙に書く
- アンラベリング：見せられなかった数字を、先になくす。公表と相手の投稿の順番（リー括弧）
- 逆最適化は答えが1つに決まらない。相手の地図（公開の情報）で計算し直し、2つの癖で目的の候補を絞る
- 結論は、ICD 203 の確からしさの7段階と、確信度を分けて書く。見つかるはずのものを、見つかる前に書く
