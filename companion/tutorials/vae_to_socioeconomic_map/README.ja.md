# VAEの潜在空間を「社会経済分析の地図」に変えるには

VAE（変分オートエンコーダ）の潜在空間に、リーマン計量という「定規」を当ててよいかを確かめるための3つの条件を、地図のたとえで解説する入門資料。Qiitaの連載「ジオメトリック・インテリジェンス」の第1回の記事（2026年3月10日公開、2026年11月1日全面改訂）を、PDFにしたものである。

## 対象読者

- 企業や官庁で働く、Python機械学習エンジニア
- 経営コンサルタント
- 政策コンサルタント
- 機械学習（AI）とAIエージェントに明るい、国会議員の政策スタッフ・秘書

## 内容

VAEの潜在空間は、画像の生成では優れた力を発揮する。しかし、社会経済データの潜在空間を「地図」として使い、距離や曲がり方を測ろうとすると、そのままでは正しい答えが得られない。地図が破れていたり（島に分かれる）、折りたたまれていたり（遠い場所が重なる）、縮尺が場所によってゼロになっていたり（潰れる）するからである。本稿は、潜在空間を「定規を当ててよい地図」にするための条件を、数式をほとんど使わずに説明する。

主要トピック:

- VAEの仕組み（エンコーダ、サンプリング、デコーダ）と、潜在空間が確率分布として作られる理由
- β-VAEとディスエンタングルメント（コラム：VAEとGAN）
- 社会経済データの潜在空間を「地図」として使うときの問題点
- 地図に定規（リーマン計量）を当てるための3つの条件と、なめらかさ（エンジニア向けの判定の目安つき）
- 「多様体」と「可微分多様体」の直感的な説明
- 業界・政策領域ごとのデータの制約と、条件を満たすための試行錯誤（架空のケーススタディより）
