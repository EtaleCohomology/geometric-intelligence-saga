# 専門家の座標と、データの地図をつなぐ（GI理論 番外編）

Qiita の記事「【GI理論 番外編】専門家の座標と、データの地図をつなぐ」のコードです。

架空のデータで、２つの方法を確かめます。

| 実験 | 内容 |
|---|---|
| `method2` | 方法２：先に地図（VAE）を作り、後から専門家の座標をつなぐ。専門家の座標の上の引き戻し計量、最小特異値、専門家の座標で表せない変動、外挿の確認 |
| `method1` | 方法１：最初から専門家の座標を潜在空間の一部として学習する。言い当ての精度、漏れの確認、z_自由 ごとに変わる定規、立方体の角の近くの計量を2つの座標（専門家の座標と、シグモイドを通す前の値）で測る比較 |
| `geodesic` | 方法２の地図で、専門家の座標の上に測地線を引き、直線の道と比べる |
| `diagnose` | つぶれかけた方向が、モデルの失敗か、データの性質かを見分ける |
| `adversary` | 漏れへの手当て（z_自由 から専門家の座標を当てようとする役と競わせる） |
| `noise` | 専門家の評価のばらつきが、計量と測地線の長さをどれだけ揺らすか |
| `plus` | 方法２＋：事例ごとの残りを持ち、地図を作り直さずに事例ごとの定規を作る。真のデータの動きとの比較 |
| `fewlabels` | 方法２を、直線の写像とネットワークの写像、座標の付いた事例20件・50件・200件で比べる |
| `verbal` | 言葉の段階（低い・中くらい・高い）の座標を、区間のラベルとして使う |
| `curvature` | 専門家の座標の2次元の切り口のガウス曲率と、その符号の安定 |
| `gluzman` | Gluzman 氏の3つの段階の道筋を、データの定規で測地線と比べる（数値は架空。実在の戦略についての結論ではない） |

## 実行方法

    pip install -r code/requirements.txt
    python code/gi_expert_coordinates_jax.py method2

数値はすべて架空のものです。考え方を確かめるための教材です。
