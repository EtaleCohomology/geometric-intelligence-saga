# GI理論 実践教材

GI理論のケーススタディ・ノベル（業界別、政策領域別）を素材に、実務で多様体を作り、分析し、その正しさを示すまでの流れを整理した教材。

## 目的

ケーススタディ・ノベルの中では、データから微分可能多様体を作り、その上で分析を行い、パイプラインの正しさを関係者に示す場面が、物語の流れの中に分かれて描かれている。本教材は、それらを作品を横断して整理し、実務で同じ作業を行うときの考え方と手順を学べるようにしたものである。

## 収録内容

はじめて読む方は、次の順番をお勧めします：
01 → 02（必要に応じて） → 03 → 04

### `01_manifold_quality_checklist_JA.pdf`

**データから微分可能多様体をつくる ── 品質チェックリストに合格するまでの試行錯誤**

7つのケーススタディで、品質チェックリスト（命題1.1の3条件）のどの条件で、なぜ不合格になり、どう合格したかを、作品ごとに文章と表で整理する。日本語のみ（現時点）。約21ページ。

### `02_manifold_quality_checklist_detailed_JA.pdf`

**（詳細版）産業固有のデータの制約と、品質チェックリストに合格するまでの試行錯誤**

01の詳細版。業界・政策領域ごとのデータセットの特徴と制約（プロジェクトごとの別管理、基幹システムの分断、周期性、顧客ごとの機密の壁、集計した指標しか入力できない制約など）と、それを克服して合格するまでの手順を詳しく扱う。日本語のみ（現時点）。約20ページ。

### `03_analyses_on_the_manifold_JA.pdf`

**完成した多様体の上で何を分析したか**

品質チェックリストに合格した多様体の上で、各ケーススタディが行った分析とシミュレーション（スカラー曲率、Lie微分、Lie括弧、測地線と最適制御、パーシステント・ホモロジー、手術理論、シンプレクティック積分、層など）を整理する。GI理論の論文と手引書で扱っていない手法も、作品ごとに整理する。日本語のみ（現時点）。約16ページ。

### `04_verification_and_accountability_JA.pdf`

**パイプラインの正しさを、機密を見せずに示す**

各ケーススタディで、パイプラインが約束どおりに動いていることを、取締役会、政府、監督機関、議会に示すために行ったこと（形式検証、定理証明、ゼロ知識証明、差分プライバシー、連合学習、秘密分散など）を、何を示し、何を示さないかとあわせて整理する。日本語のみ（現時点）。約12ページ。

## 注記

- 各教材は、ケーススタディの原稿に記載されている範囲で整理したものである。原稿に書かれていない数値は推測で補っていない。
- 原稿の数値は物語の中の数値であり、実際のデータで計算した結果ではない。登場する企業、組織、人物、データは、すべて架空のものである。
- 一部の教材は、公開準備中の作品「敵の多様体」（中国篇）の記載も参照している。公開版で記載が変わる場合がある。
