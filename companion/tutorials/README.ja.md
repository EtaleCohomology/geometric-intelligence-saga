# チュートリアル

ジオメトリック・インテリジェンス(GI)理論を新規読者に紹介する教育資料。

## 目的

本ディレクトリのチュートリアルは、データサイエンス一般に親しみのある読者と、GI理論Volume 1・2で用いられる数学的機構との橋渡しをする入門資料である。
高校数学を前提とし、必要な微分幾何学の語彙(リーマン計量、Lie微分、測地線、最適制御)を、比喩、具体例、Python実装の断片を通じて構築する。

本チュートリアルはVolume 1・2の代替ではない。読者が本理論に取り組むための準備を整え、また概念をすばやく参照するためのリファレンスとしても機能する。

## 収録内容

### `vae_to_socioeconomic_map/`

**VAEの潜在空間を「社会経済分析の地図」に変えるには？ ―― リーマン計量を導入するための3つの条件**

Qiitaの連載「ジオメトリック・インテリジェンス」の第1回の記事（2026年3月10日公開、2026年11月1日全面改訂）。

以下を扱う:

- VAEの仕組みと、潜在空間が確率分布として作られる理由（β-VAEとディスエンタングルメントを含む）
- 社会経済データの潜在空間を、そのまま「地図」として使えない理由
- 潜在空間にリーマン計量（定規）を当ててよいかを確かめる3つの条件と、なめらかさ
- 業界・政策領域ごとのデータの制約と、条件を満たすための試行錯誤（架空のケーススタディより）

日本語のみ（現時点）。約27ページ。本ディレクトリの最初に読む資料として推奨する。

### `gi_theory_introduction_JA.pdf`

**高校数学既修者向けGI理論入門**

自己完結型の入門資料。以下を扱う:

- 第1章: VAE、pullback計量、可微分多様体の構成
- 第2章: GI理論が経営者・政策決定者に提供する10の具体的な気づき
- 第3章: 物理・化学・工学がこの数学を100年間使ってきた事実
- 第4章: なぜ社会経済データではこのアプローチが今まで利用できなかったか
- 第5章: 代替となる数学的枠組み(情報幾何学、最適輸送、拡散幾何学、ニューラルODE、GPLVM)
- 第6章: PyTorch、torchdiffeq、pydiffmap、POT等を用いたPython実装例

日本語のみ(現時点)。約48ページ。

### `gi_metrics_and_manifolds_overview_JA.pdf`

**GI理論の産業適用で関係する可能性が高い、複数の計量概念・多様体概念の全体像の整理**

研修教育用の並列解説書。高校数学レベルの読者向けの「基礎編」と、学部レベルの読者向けの「発展編」を並べて解説する。以下を扱う:

- 第1章: 多様体と地図（可微分構造、GI理論で要求される滑らかさ、接空間）
- 第2章: リーマン計量とその一般化（引き戻し計量、正定値性とフルランク条件、接続と曲率）
- 第3章: フィンスラー計量とランダー計量（風のある空間の距離、ツェルメロの航法問題）
- 第4章: H¹コホモロジー（穴と経路、ジグザグ・パーシステンス）
- 第5章: 測地線の数学
- 第6章: 最適制御（ハミルトニアン、随伴変数、ポントリャーギンの最大原理）
- 第7章: シリーズで使われる他の幾何（シンプレクティック幾何、ワイル幾何、情報幾何学、双曲幾何、Sub-Riemannian幾何、最適輸送理論）

日本語のみ（現時点）。約31ページ。
