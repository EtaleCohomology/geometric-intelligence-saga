## この解説で分かること

- データから作った「地図」が、どこかで**切れたり折れたり**していないかを、行列の**固有値**で点検する方法
- 点ごとの誤差が 0 でも、地図全体の形が間違っていることがある理由
- この点検で言えることと、言えないこと

数式は、固有値の定義と 2 階微分が分かれば追えるように書いた。証明の細部や、非可換幾何学との関係は、研究ノートのほうにある。

## 1. GI の地図とは

GI 理論は、たくさんの変数を持つデータ（たとえば、国ごと・年ごとの経済や社会の指標）を、少ない座標で表す「地図」の上で分析する。地図は、変分オートエンコーダ（VAE）で作る。

- **エンコーダ** $e$: データの点 $x$（変数がたくさん）を、地図の上の点 $z$（座標が少し）に送る
- **デコーダ** $f$: 地図の上の点 $z$ を、データの世界の点 $f(z)$ に戻す

地図の上で長さを測るには、デコーダのヤコビ行列 $J$（$f$ の偏微分を並べた行列）を使う。地図の上で小さく $\Delta z$ 動くと、データの世界では、およそ $J \Delta z$ だけ動く。その長さの 2 乗は

$$\lVert J \Delta z \rVert^2 = \Delta z^\top (J^\top J) \Delta z$$

なので、行列 $g = J^\top J$ を「地図の上の物差し」に使う。これを**引き戻し計量**という。この物差しを使うと、地図の上で最短の道（測地線）や、曲がり具合（曲率）を計算できる。

## 2. いまの点検と、その見落とし

地図を作ったら、よい地図かどうかを点検する。よく使う点検は 3 つある。

| 点検 | 何を見るか |
|---|---|
| 復元誤差 | $x$ を地図に送って戻したとき、もとの $x$ にどれだけ近いか |
| 近所の保存 | データで近い点どうしが、地図の上でも近いか |
| 最小特異値 | ヤコビ行列 $J$ がつぶれていないか（つぶれると物差しが壊れる） |

どれも、**1 つの点や、その近所**だけを見る点検である。

ここで、紙の筒を思い浮かべてほしい。筒をはさみで縦に 1 本切って開くと、長方形の紙になる。筒の上の点を、開いた長方形の上の同じ場所に送る地図を作る。デコーダは、長方形を丸めて筒に戻せばよいので、**復元誤差は 0** になる。切れ目から離れた点では、近所も保たれる。

それでも、この地図は間違っている。筒では、切れ目の左右の点はすぐ隣どうしなのに、長方形では両端に離れてしまう。地図の上で「切れ目の向こう側への最短の道」を計算すると、ぐるっと遠回りの道が出てくる。

点ごとの点検では、この種の**全体の形の誤り**が見えにくい。そこで、全体の形を、別の方法で聞いてみる。

## 3. 太鼓の音から形を聞く

数学者マーク・カッツは、1966 年に「太鼓の音を聞いて、その形が分かるか」という問いを出した。太鼓の膜は、決まった振動数でしか鳴らない。その振動数の並びは、膜の形で決まる。

いちばん簡単な例は、両端を固定した長さ $\ell$ の弦である。弦の形 $u(s)$ が

$$-u''(s) = \lambda \, u(s), \qquad u(0) = u(\ell) = 0$$

を満たすとき、弦はきれいに 1 つの音で振動する。解は $u(s) = \sin(\pi m s / \ell)$、$\lambda = (\pi m / \ell)^2$（$m = 1, 2, \dots$）である。振動数は $\sqrt{\lambda}$ に比例するので、**長い弦ほど低い音**が出る。

ここで $-u''$ を作る操作 $-\dfrac{d^2}{ds^2}$ を**ラプラシアン**と呼び、$\lambda$ をその**固有値**、$u$ を**固有関数**と呼ぶ。行列の固有値 $A v = \lambda v$ と同じ形をしている。曲面や、もっと高い次元の図形にも、同じようにラプラシアン（ラプラス＝ベルトラミ作用素）がある。

点検のアイデアは次のとおりである。

> データの「音」と、地図の「音」を聞き比べる。音が違えば、形が違う。

## 4. グラフとラプラシアン

データは、図形そのものではなく、点の集まりである。そこで、点を頂点にして、近い点どうしを辺で結んだ**グラフ**を作り、グラフの上のラプラシアンを使う。

頂点 $i$ と $j$ を結ぶ辺の重みを $w_{ij}$（結んでいなければ 0）とする。重みを並べた行列を $W$、各頂点の重みの合計 $d_i = \sum_j w_{ij}$ を対角に並べた行列を $D$ とすると、**グラフラプラシアン**は

$$L = D - W$$

である。

### 小さな例

頂点 3 つを 1 列に結んだグラフ（1 − 2 − 3、重みはすべて 1）では

$$
L = \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix},
\qquad \text{固有値は } 0,\ 1,\ 3
$$

になる（コードの Step 1 で確認できる）。

### 固有値 0 の数 ＝ 島の数

頂点の上の値の並び $f = (f_1, \dots, f_N)$ について、計算すると

$$f^\top L f = \frac{1}{2} \sum_{i,j} w_{ij} (f_i - f_j)^2$$

が成り立つ。右辺は、辺で結ばれた点どうしの値の差の 2 乗の和である。

$L f = 0$（固有値 0）なら $f^\top L f = 0$ なので、辺で結ばれた点どうしでは、必ず $f_i = f_j$ になる。つまり $f$ は、つながった塊（**島**）ごとに一定の値をとる。島が 2 つあれば、「島 A で 1、島 B で 0」と「島 A で 0、島 B で 1」の 2 つの独立な解がある。したがって、

> **固有値 0 の個数は、グラフの島の数に等しい。**

これは近似ではなく、どんなグラフでも成り立つ。たとえば、1 − 2 と 3 − 4 の 2 本の辺だけのグラフの固有値は $0, 0, 2, 2$ で、0 が 2 つある（Step 1）。

### 図形のラプラシアンに近づける

点が図形の上にたくさんあれば、グラフラプラシアンの小さいほうの固有値は、図形のラプラシアンの固有値に近づく（Belkin–Niyogi 2007）。そのためには、重みを距離から決める。このコードでは

$$w_{ij} = \exp\!\left( -\frac{\lVert x_i - x_j \rVert^2}{\varepsilon} \right)$$

（$\varepsilon$ は近所の広さを決める数）とし、点の濃い場所と薄い場所の差を取り除く正規化（Coifman–Lafon 2006）を加える。

## 5. 円の上の点で試す

半径 1 の円の上では、角度 $\theta$ の関数 $u(\theta)$ について、ラプラシアンは $-u''(\theta)$ である。$u = \cos k\theta$ や $\sin k\theta$ を 2 回微分すると $-k^2$ 倍になるので、

$$\text{円の固有値} = k^2 = 0,\ 1,\ 1,\ 4,\ 4,\ 9,\ 9, \dots$$

である（$k = 1, 2, \dots$ は $\cos$ と $\sin$ の 2 つずつ）。

円の上にランダムに 800 点を置き、グラフを作って固有値を計算すると（Step 2）:

| 近所の点の数 $k$ | グラフの固有値（小さい 5 個） |
|---|---|
| 厳密な値 | 0, 1, 1, 4, 4 |
| 100 | 0, 0.96, 0.98, 3.83, 3.91 |
| 40 | 0, 0.85, 0.86, 3.37, 3.44 |

近所を十分広くとれば、厳密な値に近い。近所を狭くしすぎると、重みの裾が途中で切れて、固有値が小さめに出る。**グラフの作り方で答えが変わる**ので、実際のデータでは、作り方を結果を見る前に決めておく。

## 6. 円筒と 3 枚の地図

### 円筒の音

半径 1 の円と、高さ 0〜3 の区間を掛け合わせた円筒を考える（上下の縁は固定しない）。固有関数は $\cos k\theta \cdot \cos(\pi m z / 3)$ のような積になり、固有値は

$$\lambda = k^2 + \left(\frac{\pi m}{3}\right)^2 \qquad (k = 0, 1, 2, \dots;\ m = 0, 1, 2, \dots)$$

である。小さい順に並べると $0,\ 1,\ 1,\ 1.10,\ 2.10,\ 2.10$ になる。

### 3 枚の地図

円筒の上に 1500 点を置き、3 種類の地図を作って、データの側と地図の側の固有値を比べる（Step 3）。

- **正しい地図**: 円筒を、輪のまま地図に写す
- **切り開いた地図**: 第 2 節の紙の筒のように、1 か所で切って長方形に開く。デコーダは完全で、復元誤差は 0
- **折った地図**: 高さ $z$ と $3 - z$ を地図の同じ点に送る。地図からは 2 つを区別できないので、デコーダは上半分に戻すしかない

| | 復元誤差 | 固有値（小さい 6 個） | データの側との最大のずれ |
|---|---|---|---|
| 厳密な値（円筒） | | 0, 1, 1, 1.10, 2.10, 2.10 | |
| データの側 | | 0, 0.87, 0.89, 0.94, 1.76, 1.80 | |
| 正しい地図 | 0.000 | 0, 0.85, 0.88, 0.92, 1.74, 1.79 | 0.020 |
| 切り開いた地図 | **0.000** | 0, **0.21**, 0.87, 0.90, 1.07, 1.73 | **0.684** |
| 折った地図 | 0.737 | 0, 0.92, 0.97, 3.48, 3.60, 3.81 | 2.541 |

（データの側が厳密な値より 1〜2 割小さいのは、点の数と $\varepsilon$ が有限だからである。点検で比べるのは、厳密な値とのずれではなく、**データの側と地図の側のずれ**である。）

### なぜ切り開いた地図は見つかるのか

切り開くと、角度の方向は「輪」ではなく、長さ $2\pi$ の「両端が自由な区間」になる。長さ $\ell$ の区間の固有値は $(\pi m / \ell)^2$ なので、$\ell = 2\pi$ では

$$\left(\frac{\pi \cdot 1}{2\pi}\right)^2 = \frac{1}{4} = 0.25$$

という、輪にはなかった**低い音**が新しく現れる。表の 0.21 がそれである。つまり、切れ目を作ると、図形はゆっくり大きく揺れる新しい振動の仕方を手に入れる。復元誤差は 0 でも、音は変わる。

### 折った地図

折ると、高さ 1.5〜3 の短い円筒になる。区間が短くなると高さ方向の音が高くなり、$(\pi / 1.5)^2 \approx 4.39$ に移る。もとの 1.10 の音は消える。こちらは復元誤差でも見つかるが、固有値は、別の道から同じ誤りを示す。

## 7. 4 つの点検

研究ノートで提案している点検は、次の 4 つである。

| # | 点検 | やさしく言うと |
|---|---|---|
| 4 | **島の数** | 固有値 0 の個数を両側で比べる。データで 2 つの塊が、地図で 1 つに貼り合わされていないか |
| 5 | **低い固有値の並び** | 小さいほうから 6 個ほどの固有値を両側で比べる。第 6 節の表がこれ |
| 6 | **熱核の署名** | 各点に熱を置いて、時間 $t$ のあと、その点にどれだけ熱が残るかを両側で比べる |
| 7 | **次元の目安** | 固有値の増え方から、図形の次元を読む |

この解説のコードは点検 4 と 5 を扱う。点検 6 と 7 の計算は、研究ノートの [`shape_checks.py`](../manifold_shape_diagnostics/shape_checks.py) にある。

### 点検 6 をもう少し

固有ベクトルは、符号を反転しても固有ベクトルなので（$v$ と $-v$）、両側の固有ベクトルをそのまま比べることはできない。そこで、点 $x$ に熱を置いて時間 $t$ たったときに $x$ に残る量

$$\mathrm{HKS}(x, t) = \sum_k e^{-\lambda_k t} \, \psi_k(x)^2$$

を使う（Sun–Ovsjanikov–Guibas 2009）。固有関数を **2 乗**しているので、符号の不定性が消える。固有値が同じでも、「どの点が一緒に揺れるか」が違えば、この値に差が出る。

### 点検 7 をもう少し

円の固有値は $k^2$ だった。$\lambda$ 以下の固有値の個数 $N(\lambda)$ は、$k^2 \le \lambda$ を満たす $k$ の数なので、およそ $2\sqrt{\lambda}$、つまり $\lambda^{1/2}$ に比例する。一般に、$m$ 次元の図形では

$$N(\lambda) \approx C \, \lambda^{m/2}$$

となる（ワイルの法則）。$\log N$ と $\log \lambda$ のグラフの傾きを 2 倍すると、次元 $m$ の目安が出る。研究ノートのコード `shape_checks.py` で円筒の点から計算すると、2.02 になった（真の値 2）。グラフの高い固有値は不正確なので、あくまで目安として使う。

## 8. この点検で言えないこと

1. **同じ音でも、形が違うことがある。** Milnor（1964）は 16 次元で、Gordon–Webb–Wolpert（1992）は平面の太鼓で、固有値がすべて同じなのに形の違う例を作った。だから、**音が違えば形は違う**と言えるが、**音が同じなら形も同じ**とは言えない。結果は「合格」ではなく、「食い違いは見つからなかった」か「黄信号」と書く
2. **グラフの作り方で答えが変わる。** 第 5 節のとおり。変数の単位（円とパーセントなど）をどうそろえるか、近所の広さ、比べる固有値の数、黄信号の基準を、結果を見る前に決めて記録する
3. **データの点が独立でない。** 収束の定理は、点が独立にばらまかれていることを仮定する。国ごと・年ごとのデータでは、同じ国の隣り合う年が似ている。ばらつきを見積もるときは、行ではなく国ごとまるごと選び直す（ブートストラップ）
4. **収束が遅い。** 理論の評価では、誤差はおよそ $(\log n / n)^{1/(2m)}$ で小さくなる（García Trillos ほか 2020）。8 次元なら、$n = 25{,}600$ 点でも約 0.61 にとどまる
5. **見えるのは、デコーダとデータのずれ。** 地図の側の音は、作り方からして、デコーダが描く図形の音とそろう。この点検で分かるのは、デコーダが描く図形が、データの本当の形とずれていないかである。地図の上で計算した最適な施策が正しいかまでは保証しない

## 9. 練習問題

**問 1.** 頂点 3 つをすべて互いに結んだ三角形のグラフ（重みはすべて 1）の $L$ の固有値を求めよ。

**問 2.** 半径 2 の円の固有値を、小さい順に 5 つ求めよ。音は半径 1 の円より高いか低いか。

**問 3.** 熱核の署名で、固有関数を 2 乗せずに $\sum_k e^{-\lambda_k t} \psi_k(x)$ を使うと、どんな困ったことが起きるか。

**問 4.** 円筒を、高さの方向に切り開くのではなく、上下の縁を貼り合わせて（$z = 0$ と $z = 3$ を同じとみなして）しまう地図を作った。新しく現れる固有値と、消える固有値を答えよ。

<details>
<summary>答え</summary>

**問 1.** $L = \begin{pmatrix} 2 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 2 \end{pmatrix} = 3I - \mathbf{1}\mathbf{1}^\top$。$\mathbf{1}\mathbf{1}^\top$ の固有値は $3, 0, 0$ なので、$L$ の固有値は $0, 3, 3$。0 が 1 つなので島は 1 つ。

**問 2.** 半径 $r$ の円では、弧の長さ $s = r\theta$ で 2 回微分するので、固有値は $k^2 / r^2$。$r = 2$ では $0, 0.25, 0.25, 1, 1$。円が大きいほど音は低い（長い弦と同じ）。

**問 3.** 固有ベクトルの符号（$\psi$ と $-\psi$）は計算の都合で決まるので、データの側と地図の側で符号がそろう保証がない。2 乗しないと、形が同じでも値が食い違って見える。重複した固有値（円の $\cos$ と $\sin$ など）では、固有空間の中で回転させても固有ベクトルなので、同じ問題がもっと大きくなる。2 乗して固有空間ごとに足すと、どちらも消える。

**問 4.** 高さの方向が長さ 3 の輪になるので、高さ方向の固有値は $(\pi m / 3)^2$ から $(2\pi m / 3)^2$ に変わる。$1.10$（$m = 1$）や $2.10$ は消え、$k^2 + (2\pi m/3)^2$ の形の値、たとえば $(2\pi / 3)^2 \approx 4.39$ が現れる。図形は円筒から、ドーナツの表面（トーラス）に変わる。

</details>
